# WIZ
This repo explains about how I POV’d and productioni-zed WIZ 

first and foremost, wiz locks down their documentation behind their tenant.

their POC/POV is set to expire in 21 days

you can check for licensing under settings —> license to see what products is the tenant licensed for you to test.

they have 3 main products - cloud (CSPM), Code (their scanner), Code Lite (bring your own scanner), Defend (runtime security)
